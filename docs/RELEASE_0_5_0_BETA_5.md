# FountainJS 0.5.0-beta.5

The homepage opens at the top on a fresh visit and honors direct links to its sections. The chart range form displays validation errors inline so the next Apply click works after a correction. The automatic refresh test now advances the browser clock and verifies that requests stop across three scheduled intervals.

The GitLab CE 19.5.3 integration passed its six local gates on editor build `1f16e1b0`, including two-node failover and rollback. Hosted staging and physical mobile verification remain open. The Directus 12.7.0 HTML field integration is in development. Both integrations are available as source in the repository. [GitLab sign-off](https://github.com/eddolo/fountainjs/blob/v0.5.0-beta.5/integrations/gitlab/COMPATIBILITY_SUITE_PLAN.md) · [Directus integration](https://github.com/eddolo/fountainjs/blob/v0.5.0-beta.5/integrations/directus/README.md)

This beta includes the chart and diagram modules and the updated collaboration defaults. Existing Yjs XML rooms require the legacy entry or an explicit migration. [Editor changes](https://github.com/eddolo/fountainjs/blob/v0.5.0-beta.5/CHANGELOG.md) · [Collaboration upgrade guide](https://github.com/eddolo/fountainjs/blob/v0.5.0-beta.5/docs/YJS_DEFAULT_ADOPTION.md)
